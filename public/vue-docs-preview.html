关于 X-Frame-Options 安全策略说明：
Vue 官方站点 (cn.vuejs.org) 服务端配置了 X-Frame-Options: DENY，出于同源防护机制，浏览器会拦截外域 iframe 直接嵌入。 本页面为模板内置的可嵌入速查文档；若需在企业内网嵌入不可控的外部站点，可通过反向代理（如 Nginx proxy_hide_header X-Frame-Options）解除限制。
1. 响应式核心: ref 与 reactive

基于 ES2015 Proxy 实现的高效深层监听。

import { ref, computed } from 'vue'

const count = ref(0)
const double = computed(() => count.value * 2)

function inc() {
  count.value++
}
2. 跨容器生命周期联动

通过 IframeBridge 实时调用宿主状态。

import { bridgeClient } from '@/core/bridge-client'

// 向宿主后台发送反馈通知
bridgeClient.showMessage('操作成功', 'success')
// 动态修改宿主当前 Tab 标题
bridgeClient.setTabTitle('新标题')
